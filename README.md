# 💭 Emotion Bubble

**Emotion Bubble** is a fun visualization project that shows emotions as colorful, moving bubbles.  
Each bubble changes its color, size, and movement based on the type and intensity of emotion.

---

## 🧠 What It Does

- Takes emotion as input (like "happy", "sad", "angry")
- Displays colorful animated bubbles
- Represents emotional intensity with bubble size and motion

---

## ⚙️ Tech Stack

- HTML, CSS, JavaScript  
- Canvas API for animation  
- (Optional) Python backend for emotion detection
